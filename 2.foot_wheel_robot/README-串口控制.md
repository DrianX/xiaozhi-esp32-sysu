# 轮足机器人 · 串口控制协议

本文档给外接控制板（小智 AI 等）使用，说明如何通过串口指令控制小车运动。

---

## 1. 硬件接线

| 小车（ESP32） | 控制板（小智 AI） | 说明 |
| :---: | :---: | :--- |
| IO4（RX） | TX | 小车接收指令 |
| IO15（TX） | RX | 小车返回应答 |
| GND | GND | **必须共地** |

> 注意：
> - 双方均为 3.3V 电平，直连即可；若控制板是 5V 电平，请加电平转换。
> - IO15 是 ESP32 的启动采样脚，控制板上电时不要把该引脚拉低。

## 2. 通信参数

| 参数 | 值 |
| :--- | :--- |
| 波特率 | 115200 |
| 数据位 | 8 |
| 校验位 | 无 |
| 停止位 | 1 |
| 行结束符 | `\n` 或 `\r\n` |

## 3. 上电与握手（自动起立）

1. 小车上电后需要约 5 秒初始化（电机校准）。
2. 初始化完成后，小车主动发送 `READY`，此后每 2 秒重发一次，直到握手成功。
3. 控制板收到 `READY` 后，发送 `HELLO`。
4. 小车收到 `HELLO`，回复 `OK`，并**自动起立**（进入站立平衡状态）。

```
小车(ESP32)                         控制板(小智AI)
    |                                     |
    |----- READY ------------------------>|
    |<----------------------------- HELLO |
    |----- OK --------------------------->|
    |           （自动起立）               |
    |<----------------------------- FORWARD |
    |----- OK --------------------------->|
```

> 建议：控制板等待收到 `READY` 后再发 `HELLO`；若发 `HELLO` 后 1 秒内未收到 `OK`，重发 `HELLO`。

## 4. 指令总览

| 指令 | 参数 | 说明 | 小车回复 |
| :--- | :--- | :--- | :--- |
| `HELLO` / `HI` / `START` | 无 | 握手，成功后自动起立 | `OK` |
| `STOP` | 无 | 停止所有运动（保持站立） | `OK` |
| `FORWARD` | [速度] [时长ms] | 前进 | `OK` |
| `BACK` / `BACKWARD` | [速度] [时长ms] | 后退 | `OK` |
| `LEFT` | [速度] [时长ms] | 原地左转 | `OK` |
| `RIGHT` | [速度] [时长ms] | 原地右转 | `OK` |
| `SPIN` | [L/R] [时长ms] | 原地转圈（默认左，一圈） | `OK` |
| `HEIGHT` | 0-100 | 设置机身高度 | `OK` |
| `UP` | 无 | 升高一档 | `OK` |
| `DOWN` | 无 | 降低一档 | `OK` |
| `STAND` / `STANDUP` | 无 | 起立 | `OK` |
| `SIT` / `SITDOWN` | 无 | 坐下 | `OK` |
| `JUMP` | [F/B/L/R] | 跳跃（默认原地跳） | `OK` |
| `SPEED` | 1-100 | 设置默认速度档位 | `OK` |
| `STATUS` / `PING` | 无 | 查询状态 | `STANDING` / `SITTING` |

> - 指令**大小写不敏感**（`forward` 与 `FORWARD` 等价）。
> - 参数之间可用空格或逗号分隔（`FORWARD 50 2000` 与 `FORWARD,50,2000` 等价）。
> - 未知指令回复 `ERR`。

## 5. 参数说明

### 5.1 速度（1-100）
- 数值越大越快，默认 60。
- 省略时使用当前默认速度（可用 `SPEED` 命令修改）。

### 5.2 时长（毫秒）
- 运动指令的第二个参数是持续时间。
- **单个参数**时：值 ≤ 100 视为速度，值 > 100 视为时长。例如：
  - `FORWARD 50` → 速度 50，一直走
  - `FORWARD 2000` → 默认速度走 2 秒后自动停
- **两个参数**时：`速度 时长`，例如 `FORWARD 50 2000` → 速度 50 走 2 秒。

### 5.3 持续 vs 定时
- 不带时长：一直运动，直到收到 `STOP` 或下一条运动指令。
- 带时长：到时自动停止（回到站立静止状态）。

### 5.4 高度（0-100）
- `HEIGHT 0` = 最低，`HEIGHT 100` = 最高，默认约 50。
- `UP` / `DOWN` 每次升降一档。
- 运动时车机会根据速度自动微降，以保持稳定（与手柄逻辑一致）。

### 5.5 转圈
- `SPIN` 默认左转一圈（约 360°）。
- `SPIN R` = 右转一圈；`SPIN L` = 左转一圈。
- `SPIN 4000` = 左转 4 秒（圈数由时长决定）。
- 转一圈的基准时长 `SPIN_360_DURATION_MS`（默认 2500ms）可在 `src/SerialCommand.cpp` 中校准。

### 5.6 跳跃
- `JUMP` 默认原地跳；`JUMP F/B/L/R` 分别向前/后/左/右跳。
- 坐下状态或正在跳跃时发送会回复 `ERR`。

## 6. 语音场景示例（小智 AI 侧映射参考）

| 语音 | 发送指令 |
| :--- | :--- |
| 往前走 | `FORWARD` |
| 往前走两秒 / 前进一点点 | `FORWARD 2000` |
| 后退 | `BACK` |
| 左转 | `LEFT` |
| 右转 | `RIGHT` |
| 转个圈 | `SPIN` |
| 停 / 站住 | `STOP` |
| 站起来 | `STAND` |
| 坐下 / 蹲下 | `SIT` |
| 跳一下 | `JUMP` |
| 往前跳 | `JUMP F` |
| 升高一点 | `UP` |
| 降低一点 | `DOWN` |
| 快一点 | `SPEED 80` |

## 7. 常见问题

- **收不到 `READY`？** 检查 TX/RX 是否交叉连接、是否共地、波特率是否为 115200。
- **`HELLO` 后没自动起立？** 确认小车回复了 `OK`；若没有，重发 `HELLO`。
- **转圈不是刚好一圈？** 调整 `SPIN` 的时长参数，或修改 `src/SerialCommand.cpp` 里的 `SPIN_360_DURATION_MS`。

## 8. 附：重新启用蓝牙手柄

代码保留了原 Xbox 蓝牙手柄逻辑，默认关闭。如需改回手柄控制，把
`src/main.cpp` 顶部的 `#define ENABLE_XBOX_CONTROLLER 0` 改为 `1` 后重新编译即可。

使用说明

Web Serial · 本地实时姿态观测

启动

双击 start.bat，页面会自动在 Chrome 或 Edge 中打开。Web Serial 只支持 Chromium 内核浏览器，并且需要通过 localhost 访问。

连接 ESP32

  1. 点击「选择串口」，在浏览器弹出的设备窗口中选择 ESP32。
  2. 确认波特率（默认 115200，需与下位机一致）。
  3. 点击「连接串口」。浏览器出于隐私限制，下拉框中只显示已经授权的端口。

拔插设备后，点击端口右侧的刷新按钮更新列表。从未授权过的新设备不会自动出现，需要再点一次「选择串口」在浏览器设备窗口中授权。

串口数据格式

每行一条数据，支持以下格式，单位：姿态 deg、加速度 g、角速度 °/s、温度 °C。

{"roll":1.25,"pitch":-3.40,"yaw":128.6,"ax":0.02,"ay":-0.01,"az":1.00,"gx":0.4,"gy":-0.2,"gz":1.1,"temp":31.5}

CSV（9 列）：roll,pitch,yaw,ax,ay,az,gx,gy,gz

CSV（6 列）：ax,ay,az,gx,gy,gz，仅由加速度估算 Roll / Pitch。

键值对：roll=1.25 pitch=-3.4 yaw=128.6 ax=0.02 ...

若下位机格式不同，请查看「原始数据」核对，并在 src/protocol.js 中补充字段别名。

三维模型与校准

ESP32 模型来自工作目录中的 esp32-3D模型.step，已转换为经 Meshopt 压缩的 assets/esp32.glb。页面会先显示轻量预览模型并立即响应姿态，高清模型在后台载入完成后自动替换，不会出现阻塞式加载界面。

默认姿态约定：机体 X 朝前、Y 朝左、Z 朝上；Roll 正值右侧下沉，Pitch 正值抬头，Yaw 正值俯视逆时针。若固件符号或安装方向不同，打开视图右上角的「视图校准」逐项反向（该设置只影响 3D 显示）。CSV 与 JSON 的串口数据规范见 docs/serial-output-spec.md。

曲线与导出

曲线窗口支持 10 / 30 / 60 秒；鼠标悬停可查看十字线和同步数值。右上角按钮可打开数据表或导出当前缓冲的 CSV。没有硬件时，可点击顶部「演示数据」预览全部效果。

Yaw 在 ±180° 回绕处会出现竖直跳变，这是角度表示方式造成的，不代表数据异常。
